# Product Rules

## Goal
このプロジェクトは、既存の BattleSimulator を土台にして、個人用の戦闘シミュレーション環境へ改造していく。
主要な利用目的は、明示的な戦術入力から結果分布を生成し、代理モデルの
学習・検証に利用できる再現可能な戦術シミュレーターを構築することである。

## Priorities
- 代理モデルが実装順や暗黙の乱数を戦術効果として学習しないことを最優先する
- 入力、rules version、seed、結果、終了理由を追跡できることを優先する
- まずは自分が扱いやすいシミュレーション機能を優先する
- 既存機能を壊すより、拡張で対応することを優先する
- 実験しやすさと後から仕様を変更しやすい構造を重視する

## Scope
- `battlesim/` 配下のシミュレーション機能拡張
- データセットの差し替えや追加
- 可視化やアニメーションの調整

可視化方針の詳細は `docs/visualization-rules.md` を参照する。

## Near-Term Product Direction
- 既存 API の戻り値を維持しながら、結果契約と同時解決カーネルを拡張する
- 独自仕様は「戦闘ロジック」「地形」「AI」「可視化」を分けて追加する
- 既存データセットでも動くことを維持しながら、自分用データセットへ差し替えやすくする
- 最初の代理モデルは勝者、終了理由、戦闘時間、残存戦力を目的変数とする

## First Customization Targets
- 地形を無効化したときの挙動を明確にする
- ターゲティングなど戦闘結果へ直接影響する処理の整合性を上げる
- 後から独自ユニットや独自 AI を足せるように、拡張ポイントを明文化する

## Out of Scope
- パッケージ公開を前提にした整備は現時点では必須ではない
- 弾丸 object、morale、suppression、複雑な同盟外交は rules version 1 の対象外とする
- 仕様判断と回帰基準がない大規模リファクタは行わない

## Decision Rule
迷った場合は、汎用性よりも「自分の用途で一貫して使いやすいこと」を優先する。
